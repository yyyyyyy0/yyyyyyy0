# Hi, I'm yyyyyo

I build tooling for AI coding agents, and small macOS utilities for things I want on my own machine.

## AI coding agent tooling

| Project | What it does |
|---------|-------------|
| [**mantra**](https://github.com/yyyyyyy0/mantra) | My personal Claude Code harness — four short rule files, a planner and reviewer agents, and a guard hook that blocks destructive commands |
| [**myak**](https://github.com/yyyyyyy0/myak) | Persistent memory for Claude Code — indexes session transcripts locally (SQLite FTS5, optional vector search) and recalls them through hooks, MCP tools, and a CLI |
| [**maw**](https://github.com/yyyyyyy0/maw) | Coordination contract for parallel coding agents in one repo — `claim`, `handover`, `takeover`, and `doctor` on top of git worktrees |
| [**kxxx**](https://github.com/kxxx-dev/kxxx) | Agent-safe secret runtime — broker operations through the CLI so LLMs never see raw credentials |
| [**ma-skills**](https://github.com/yyyyyyy0/ma-skills) | UI design & review skills for AI coding agents, grounded in the philosophy of 間 (ma) |
